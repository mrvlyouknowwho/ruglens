Honeypots on Ethereum are more expensive to run — and more sophisticated

Gas on mainnet is not cheap, so Ethereum scams tend to be less throwaway and more carefully disguised than the mass-minted tokens on cheaper chains. That makes a mechanical check more valuable, not less: a contract that looks clean in the explorer can still gate the sell behind a hidden owner, a blacklist, or a tax that only bites on exit.

What gets checked on Ethereum

  • Live sell simulation via honeypot.is — a real buy-then-sell on mainnet, so a "buys work, sells revert" trap is caught before you spend anything.
  • Buy and sell tax — including the classic low-buy / punishing-sell asymmetry.
  • Owner powers — mintable supply, proxy upgradeability, hidden owners, reclaimable ownership, blacklist and cooldown functions.
  • Holders and liquidity — holder concentration and Uniswap pool depth, so a token propped up by a handful of wallets is obvious.

FAQ

How do I check an Ethereum token for a honeypot?

Paste the ERC-20 contract address above with the network set to Ethereum. The tool runs a live on-chain sell simulation and reads contract, holder and liquidity data to flag honeypots and rug risks.

Can a verified contract on Etherscan still be a honeypot?

Yes. Verification only means the source matches the bytecode — it says nothing about whether the code lets you sell. A hidden owner, blacklist or exit tax can sit inside a fully verified contract. Always simulate a sell.

Is the Ethereum checker free?

Yes, it runs entirely in your browser on public APIs with no account or wallet connection.
